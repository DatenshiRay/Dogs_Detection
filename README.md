# Классификация пород собак с помощью **EfficientNet-B3**

Модель классифицирует изображение собаки по одной из **120 пород**, используя предобученную сеть EfficientNet-B3 и двухэтапное дообучение на датасете Stanford Dogs.

---

## Результаты

| Метрика                      | Значение           |
| ---------------------------- | ------------------ |
| **Best Validation Accuracy** | **0.897**          |
| **Test Accuracy**            | **0.891**          |
| **Test Accuracy (TTA)**      | **0.888**          |
| Количество классов           | 120                |
| Размер изображений           | 300 × 300          |
| Размер датасета              | 20 580 изображений |
| Backbone                     | EfficientNet-B3    |

## Данные

Основной датасет:

* **Stanford Dogs Dataset**
* 120 пород собак
* около 20 000 изображений
* XML-аннотации с координатами объектов

В проекте предусмотрена возможность объединения данных с дополнительным датасетом **Tsinghua Dogs**, однако итоговая модель обучалась только на Stanford Dogs.

| Параметр                     | Значение   |
| ---------------------------- | ---------- |
| Изображений                  | 20 580     |
| Пород                        | 120        |
| Минимум изображений на класс | 50         |
| Формат                       | JPEG + XML |
| Использован Tsinghua Dogs    | Нет        |

Перед обучением выполняется:

* извлечение собак по bounding box из XML-аннотаций;
* нормализация названий пород;
* фильтрация редких классов;
* объединение изображений в единую структуру каталогов.

## Архитектура модели

### Backbone

* EfficientNet-B3 (ImageNet pretrained)
* Размер входного изображения: **300 × 300**
* Модифицированный классификатор под 120 пород

### Регуляризация

* Dropout
* MixUp
* CutMix
* Data Augmentation

### Аугментации

Для обучающей выборки используются:

* RandomResizedCrop
* Horizontal Flip
* Color Jitter
* Random Rotation
* MixUp
* CutMix

---

## Обучение

Обучение выполняется в две стадии.

### Фаза 1 — обучение классификатора

Backbone заморожен, обучается только новый классификационный слой.

* 5 эпох
* AdamW

### Фаза 2 — Fine-Tuning

Размораживаются все параметры модели.

* до 10 эпох
* AdamW
* CosineAnnealingWarmRestarts
* Early Stopping

Используются разные learning rate:

| Часть сети | Learning Rate |
| ---------- | ------------- |
| Backbone   | 5e-5          |
| Classifier | 5e-4          |

---

## Борьба с дисбалансом классов

Для компенсации различий в количестве изображений между породами используется:

* `WeightedRandomSampler`

Это позволяет реже представленные породы показывать модели так же часто, как и популярные классы.

## Test Time Augmentation (TTA)

На тестовой выборке используется усреднение предсказаний нескольких версий изображения.

Это позволяет повысить устойчивость модели к изменениям масштаба и положения объекта.

---

## Инференс

Модель возвращает список наиболее вероятных пород с вероятностями.

Пример результата:

```text
1. golden_retriever     92.4%
2. labrador_retriever    4.1%
3. flat_coated_retriever 1.8%
4. nova_scotia_duck_tolling_retriever 0.9%
5. kuvasz 0.3%
```

Поддерживаются:

* локальные изображения;
* изображения по URL.
